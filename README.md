# 汉字小丑牌 · Chinese Character Balatro

一款给汉语学习者玩的**闯关卡牌游戏**：把手里拿到的汉字卡片和怪物出示的字组成词语，就能造成伤害。

**在线试玩：** https://owlminerva593-lang.github.io/hanzi-xiaojoupai/

## 玩法

- 怪物出示一个字，你手里能和它**组成词语**的牌才能造成伤害；打错会被反击
- 出牌张数**恰好等于**幸运数字（一~六）时，伤害 ×该数字
- 每层 5 只怪物，第 5 只是 **BOSS**（中风 / 伏火 / 单行 / 大病 / 阴阳 / 赤火 / 孤阳 / 盗汗），各有特殊能力
- 击败怪物后**朗读词语两遍**巩固记忆，并且**每击败一只怪物换一首 BGM**
- 战斗中击败怪物可获得**中药材道具**（共 46 件，商店购买，可折价出售）
- 每层可开启「全员挑战」：一次迎战本层全部 5 只怪物

## 学习内容

- 10 个核心词语：微信 / 支付宝 / 认识 / 高兴 / 贵姓 / 上课 / 学习 / 留学生 / 老师 / 医生
- 怪物头顶提供**英文释义**（母语提示），组出词语后显示大号彩色汉字 + 拼音 + 英文
- 牌堆混入大量**形近字干扰牌**（如「信 / 估」「课 / 颗」「微 / 徽」），练眼力

## 技术说明

- 纯前端单文件（HTML + CSS + JS），无框架、无后端、无外部依赖
- 音效与 BGM：WebAudio 实时合成（8bit 风格）
- 中文发音：浏览器 `speechSynthesis`
- 成绩保存在浏览器 `localStorage`（本机记录，不跨设备同步）
